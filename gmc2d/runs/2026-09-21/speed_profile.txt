A. THE ARITHMETIC, BEFORE ANYTHING IS RUN
----------------------------------------------------------------------
network parameters                          1,676,678
flops per network evaluation                3,333,376
network evaluations per sample                     10
flops per CELL CROSSING (GMC)              33,333,760
flops per SCATTERING EVENT (MC, est.)              30
ratio                                       1,111,125 x

Read that ratio, then discount it.  In raw arithmetic one generated
crossing is worth about 1,111,125 scattering events, which sounds
fatal.  It is not the whole story, because the two sides run at wildly
different efficiency:

  GMC network, batch 4,096              289 GFLOP/s   (dense matmuls)
  MC scattering loop                   0.12 GFLOP/s   (measured, 254 ns/scatter)

The network runs at the machine's arithmetic limit.  The Monte Carlo
walk does not run on arithmetic at all -- it is a random number, a
logarithm, two divisions and a branch, and its cost is dominated by the
dependent chain and the RNG, not by flops.  So the baseline wastes about
2,447x of this CPU's arithmetic capability, and that waste is the
only reason the crossover is a few hundred mean free paths away rather
than a million.

The time ratio, which is the one that matters, is in section H.

C. HOST LOOP vs NETWORK: the same solve with a FREE model
----------------------------------------------------------------------
The second row replaces the ODE right-hand side with a function that
returns zeros.  Shapes, batching, tallies, rotations and dtype
conversions are identical; the arithmetic is gone.  Its wall time is the
floor GMC could reach with a perfect, instantaneous model.

  variant        wall (s)   network   birth MC      host    us/crossing
  real model      11.276    11.005      0.128     0.143          68.01
  free model       0.338     0.203      0.001     0.134           1.84

  MC on the same problem, scaled to the same 20,000 particles: 0.0378 s
  GMC as it stands is 298x MC's time; with a free model it
  would still be 9x.

----------------------------------------------------------------------
H. BREAK-EVEN PROJECTION
----------------------------------------------------------------------
MC wall time per particle grows as W^1.41 over the thick end of the
sweep.  GMC's is flat in W -- the whole point of the method.  Where the
two lines cross is the crossover.

GMC per particle is split into a host floor of 16.9 us that no model
work touches, plus the network, which each intervention divides:

  intervention                          network  us/particle    W* (mfp)
  as measured (heun 5, 10 nfe)                1x       563.8         288
  euler 4 steps (4 nfe)                       2x       267.2         170
    + width 128 depth 3                       9x        78.4          71
  distilled 1 nfe + width 64 depth 3         79x        23.8          31
  network free (the host loop alone)    1000000x        16.9          24

The last row is the limit of this driver: even an instantaneous model
leaves the Python/NumPy/torch loop, and that alone needs cells about
24 mfp wide before it beats numba MC.
